# Syrena-okretowa
Projekt wykonany w ramach laboratorium na Politechnice Gdańskiej.

**Opis projektu**
Zadanie polegało na zaprojektowaniu od podstaw schematu ideowego oraz dwustronnego obwodu drukowanego (PCB) dla generatora sygnału dźwiękowego (syreny okrętowej). Sercem układu jest popularny timer NE555, współpracujący z układem wzmacniającym opartym na tranzystorach bipolarnych, który wysterowuje głośnik. 

**Zakres wykonanych prac**
* Odwzorowanie i analiza działania schematu ideowego w środowisku Eagle.
* Zaprojektowanie optymalnego rozmieszczenia elementów z myślą o lutowaniu przewlekanym (THT).
* Ręczne poprowadzenie ścieżek na dwóch warstwach miedzi.

**Spis plików i ich zawartość**
* **Wiciński.sch** – Schemat ideowy syreny okrętowej.
* **Wiciński.brd** – Projekt obwodu drukowanego.
